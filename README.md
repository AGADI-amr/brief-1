# Apprentissage du HTML

1. Se familiariser avec le HTML et apprendre à structurer ma première page : l’élément `<head>`, l’élément `<meta>`, le `DOCTYPE` et l’élément `<body>`.

2. Apprendre les éléments de titre et de paragraphe.

3. Se familiariser avec les attributs et apprendre à les utiliser.

4. Apprendre l’élément `<img>`, l’élément `<a>`, l’attribut `href` et la différence entre une URL absolue et une URL relative, ainsi que la manière de créer un lien vers un fichier ou une section à l’aide d’un identifiant (`id`), en utilisant `href="#..."` et `href="style.css"`.

5. Apprendre les éléments `<li>`, `<ul>` et `<ol>`, ainsi que la manière de créer des liens.

6. Apprendre la différence entre les éléments de type bloc et les éléments en ligne, entre les éléments `<div>` et `<span>`, ainsi que l’élément `<button>`.

7. Apprendre la sémantique HTML, les éléments non sémantiques, ainsi que les éléments `<section>`, `<main>`, `<nav>`, `<header>`, `<footer>` et `<article>`

# Apprentissage du CSS

1. Se familiariser avec le CSS et comprendre pourquoi nous l’utilisons.

2. Apprendre la syntaxe du CSS : les sélecteurs, les déclarations, les propriétés et les valeurs.

3. Approfondir les connaissances sur les sélecteurs CSS : les sélecteurs simples, les combinateurs, les pseudo-classes, les pseudo-éléments et les sélecteurs d’attributs.

4. Apprendre les différentes façons d’appliquer le CSS : externe, interne et en ligne, ainsi que les erreurs en CSS.

5. Apprendre à utiliser les couleurs, les polices de caractères et les arrière-plans en CSS.

6. Apprendre à utiliser les bordures, les marges et les espacements internes en CSS.

7. Comprendre le design responsive, l’approche « mobile first » et apprendre à utiliser différentes unités de mesure en CSS, telles que `px`, `vh`, `vw`, `em`, `rem` et `%`.
